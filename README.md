# student_project

Console application developed in Python to manage a student inventory. Allows you to add, view student list, search, update, delete products safely.

## features

1. Add students 
2. View student list 
3. Search for students 
4. Update student information 
5. Delete student
6 Exit

## Technologies used
python 3
- Structured programming
- Exception handling (`try/except`)
